# Marathon

Браузерная игра-квест: парень с дивана решает пробежать марафон.

Главы-квесты о подготовке (выбор ответа меняет форму, здоровье и тактику) чередуются с забегами-раннерами по пяти марафонам: Москва, Берлин, Лондон, Нью-Йорк, Токио. На трассе — препятствия, контроль пульса и задания тренера: вода и бананы на пунктах питания, помощь упавшему бегуну, фото у достопримечательностей, «пятюни» болельщикам.

## Управление
- Пробел / ↑ — прыжок
- ← / → — темп
- E / ↓ — действие (взять воду, помочь, помахать фотографу)
- P / Esc — пауза

На телефоне — кнопки под игровым экраном.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.
